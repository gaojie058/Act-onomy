What is Act-onomy?

Act-onomy is a taxonomy for describing and analyzing AI agent behavior at runtime. It provides a shared vocabulary of 10 actions, 46 subactions, and 120 leaf categories to help people make sense of what agents do.

Agents produce long reasoning trajectories and execution traces, but these records are often difficult to interpret at scale. Act-onomy connects behavior labels to quoted evidence, helping researchers, agent designers, and users examine how an agent plans, reasons, executes, evaluates, and adapts.

The taxonomy was developed through Grounded Theory. The accompanying repository contains the living codebook, research datasets, automated analysis tools, and a protocol for extending the vocabulary as new agent behaviors emerge.

Act-onomy paper (Gao et al., NeurIPS 2026)Code, data, and analysis tools

Overview

  • Purpose — Describe and analyze agent behavior at runtime.
  • Structure — Action → Subaction → Leaf category.
  • Evidence — Each trace annotation is linked to the words behind it.
  • Applications — Compare behavioral profiles across agents and examine differences within a single agent’s trajectories.
  • Extension — Adapt the codebook to behaviors in new agent systems.

The released taxonomy

  • 10 actions, including Planning, Reasoning, Executing, and Reflecting.
  • 46 subactions that distinguish more specific kinds of behavior.
  • 120 leaf categories with definitions or examples from the codebook.

How Was It Developed?

Act-onomy uses a Grounded Theory approach to turn descriptions of agent behavior into a structured, extensible vocabulary.

  1. Ground the vocabulary. Collect behavior descriptions from agent research, review their evidence, and refine category boundaries.
  2. Apply it to trajectories. Link labels to quoted evidence and examine patterns across agents and across runs.
  3. Keep it open to change. Propose new behaviors through a documented extension protocol.
